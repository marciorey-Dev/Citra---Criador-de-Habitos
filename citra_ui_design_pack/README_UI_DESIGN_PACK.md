## 🎨 Camadas Incluídas em Cada Arquivo .PSD

Cada arquivo `.psd` na pasta `2_psd_layered/` foi construído com camadas reais e posicionamento independente, permitindo editar, ocultar ou mover componentes no Photoshop, GIMP, Figma ou Illustrator:

| Camada | Descrição |
| :--- | :--- |
| **`StatusBar`** | Barra de status superior (Horário 14:59, 5G, Sinal de Rede, Bateria 100%). |
| **`TopAppBar`** | Barra superior com ícone cítrico, título da seção, busca e menu de opções. |
| **`[Screen]Content`** | Conteúdo principal da tela (cards, listas, dial do timer, fórmulas, gráficos). |
| **`FloatingActionButton`** | Botão de ação flutuante circular com sombra e ícone (+). |
| **`BottomNavigationBar`** | Barra de navegação inferior com as 5 seções e indicador ativo de aba. |
| **`Background`** | Fundo escuro sRGB (#141311) harmonizado com o tema Material 3. |
